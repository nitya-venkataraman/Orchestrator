### US-1: Weekly summary report
The analyst needs a weekly summary report so the team can review progress.

**Acceptance criteria**
- Given it is Monday, when the report job runs, then a summary for the prior week is generated.
- Given the report is generated, when it completes, then the analyst is notified by email.
