# User Stories — Search filters

_Generated: 2026-09-02 · Sources: samples/bad-missing-open-questions (notes)_

## Personas
- **Shopper** — a customer browsing the product catalogue.

## Epic: Discovery

### US-1: Filter products by category
**As a** shopper, **I want to** filter the catalogue by category **so that I can** narrow results to what I need.

**Acceptance criteria**
- Given the catalogue is open, when I select a category, then only products in that category are shown.
- Given no products match, when the filter is applied, then an empty-state message is shown.

**Priority:** High
