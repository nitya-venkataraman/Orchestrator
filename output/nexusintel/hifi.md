### What each state shows

- **01 - Screening Queue** — loading: summary tiles with '—' placeholders + Bar Loader · empty: 'No profiles assigned to you' + Start new profile · error: queue failed, filter kept + Retry · success: Toast 'Chase sent to sponsor', row badge → 'Awaiting · chased 14:32' · disabled: Chase disabled + Tooltip 'Re-sent 2h ago · chase again after 16:32'
- **02 - Precedent Search** — loading: per-repository Progress rows (CRM, document repository, SharePoint, shared drives, mailboxes) · empty: 'No prior contact found', all five repositories named + Widen to sponsors and subsidiaries · error: partial results with an Error banner naming the missing mailbox source · success: Toast 'Precedents attached' · disabled: Attach to profile disabled + Tooltip 'Select at least one entry to attach'
- **03 - Document Extraction** — loading: per-page parsing Progress · empty: 'No terms extracted' with likely causes + Enter terms manually · error: service unavailable, uploads kept + Retry / Enter manually · success: Toast '4 terms committed' · disabled: 'Commit terms (2 conflicts)' disabled + Tooltip
- **04 - Borrower Profile** — loading: metric tiles '—' + Bar Loader · empty: 'Nothing committed yet' + Go to document extraction · error: 'Capital IQ feed failed' banner naming the last known value and date · success: Toast 'Submitted for review' · disabled: 'Submit — 1 input outstanding' disabled + Tooltip naming both blockers
- **05 - Corporate Structure** — loading: progressive derivation Progress · empty: 'Structure could not be derived', documents named + Build structure manually · error: 'Partial derivation' banner, unverified branches kept and badged · success: Toast 'Structure confirmed' with reviewer + time · disabled: 'Confirm structure (1 unverified)' + Tooltip naming the branch
- **06 - Risk Review** — loading: first-read band first + Bar Loader · empty: Success banner 'No challenge flags and no open threads' listing what was checked + Sign off enabled · error: Error banner, 'Unverifiable figures' tile → 1 · success: Toast 'Sign-off recorded' · disabled: caption names the unverifiable figure + Tooltip
- **07 - Portfolio Watch** — loading: attention band shown, headroom row replaced by Bar Loader · empty: Success 'Nothing needs your attention today', 40 monitored, refresh time · error: Warning 'Scores are not current' with computation time · success: inline Success acknowledgement · disabled: Acknowledge disabled + Tooltip 'Outside your desk scope · Infrastructure EU'
- **08 - Position Detail** — loading: narrative + headroom shown, exposure/signals column replaced by Bar Loader · empty: 'No active signal', covenants checked + refresh time · error: 'Interest cover covenant not measurable' + Supply the threshold · success: inline Success with timestamp and who was notified · disabled: Escalate to workout review disabled + Tooltip naming the required role

## Components used

Every component is a linked instance from the KKR Internal Design System library; none are detached and none are local look-alikes.

| Component | Used for |
|---|---|
| Side Navigation (State=Open) | App shell, 240 px; slot holds Search Bar + Navigation Button × 3, active item per page |
| Navigation Button | Screening Queue / Precedent Search / Portfolio Watch (Open=Active on the current section) |
| Search Bar | Global entity search at the top of the side nav |
| Header Section (H1) | Page title + subheader; Right Component slot holds the page actions |
| Button | Primary / Secondary header actions, Tertiary-Inline row actions, Disabled for the disabled state |
| KPI Card (No Trend) | Queue summary, key metrics, first-read band |
| Badge | Blocker status, extraction confidence, desk, unverified / unrated, signal role — always with a text label |
| Inline Notification | Coverage, derivation, deadline, freshness banners; challenge flag; review threads; empty and error states |
| Meter | Covenant headroom (see gaps — fill is not data-bound) |
| Separator | Row dividers inside list containers |
| Bar Loader / Progress | Loading states (Progress where the spec asks for per-source or per-page progress) |
| Toast (Success) | Success states that confirm and move on (01–06) |
| Tooltip (Dark) | Reason for every disabled control |

**Tokens.** All locally built layers (page shell, section containers, rows, text) bind to KKR variables: `surface/pageSubtle`, `surface/default`, `surface/subtle`, `Text/primary|secondary|tertiary`, `border/muted`, `BuildTokens/Spacings/spacing_xxs…spacing_l`, `BuildTokens/Corners/surface`, `BuildTokens/Borders/border_m`. Text uses KKR text styles only: `Headings/heading_03`, `Body Text/body_l`, `Body Text/body_s`, `Labels/label_s`. An audit of all 48 frames found **0 unbound fills, 0 unbound gaps, 0 text layers without a style**.

State is never carried by colour alone: every Badge and Inline Notification has a text label, and notifications also carry a distinct icon. Disabled controls name their blocker in the label or caption and again in a Tooltip.

### Observations

- KKR `heading_03` and the KPI data style apply title case, so the wireframe's 'Needs review — 3 terms' renders as 'Needs Review — 3 Terms' and '11 months' as '11 Months'. The copy is unchanged; the casing comes from the DS styles.
- A disabled Primary Button in the KKR library renders without a container fill. It reads as text, which is why every disabled frame also states the reason.
- 08 - Position Detail gained a Tertiary Inline Button 'View underwriting profile' under the threshold source. The wireframe had this only as a hotspot, and the prototype needs a control for it.
- The wireframe carries desktop only (1440 × 1024), so no other breakpoint is drawn.

## Prototype

The hi-fi page is wired as a click-through prototype. Open the page in Figma, press **Present**, and choose a flow:

| Flow | Starts on | Path |
|---|---|---|
| Associate → Reviewer: screen, profile, sign off | 01 - Screening Queue | queue row → 04 profile → View corporate structure → 05 → Confirm (success) → 04 → Submit for review (success) → 06 → select the blocking thread (resolved: 06 / empty) → Sign off (success) → 01 |
| Managing Director: standing watch | 07 - Portfolio Watch | attention row → 08 → Acknowledge signal (success) · View underwriting profile → 04 |

- **Everywhere (48 frames):** the side nav (Screening Queue, Precedent Search, Portfolio Watch) and the entity search (opens 02) work on every frame, including state frames.
- **All 11 Stage-4 flows are covered:** row → 04, search → 02, nav → 07, Attach → 03, Commit → 04, View corporate structure → 05, Confirm → 04, Submit → 06, Sign off → 01, attention row → 08, View underwriting profile → 04.
- **Success frames:** actions that commit work land on their success frame first (02, 03, 04, 05, 06). Click the toast or anywhere on the page to continue to the next screen.
- **States on the path:** on 01, Chase → success (Toast, row badge updated) → Chase again → disabled (Tooltip gives the reason). On 06, the disabled Sign off opens 06 / disabled with its reason. On 07, Acknowledge → inline success.
- **Not wired:** Export, Upload, Request access, Escalate, and the empty, error and loading frames. Those frames are for review, not the happy path.
- **Interactions:** 48 page-flow links + 188 nav and search links, all On click → Navigate, Dissolve 200 ms.

## Design System Gaps

| Screen | Need | Why no existing component or variable covers it |
|---|---|---|
| All screens | A list / table row for queue, timeline, extracted-term, add-back, exposure and structure rows | The library publishes no list-row or data-grid component usable on canvas — the AG Grid pages are documentation frames and 'To-Do List using AG Grid' is a fixed task-list composite. Rows are auto-layout frames composed from KKR text styles, Badge, Button (Tertiary / Inline) and Separator, with every fill, gap and padding bound to KKR variables. |
| 04 - Borrower Profile, 06 - Risk Review | A provenance line under each metric naming the clause or feed it came from | KPI Card's only secondary text is the 'As Of' date chip, which prefixes 'As Of:' and truncates at card width. The source line is set in body_s / Text/tertiary beneath the card inside a 'Metric Tile' wrapper. |
| 01 - Screening Queue / loading, 04 - Borrower Profile / loading, 06 - Risk Review / loading, 07 - Portfolio Watch / loading, 08 - Position Detail / loading | Skeleton rows and tiles held at final height so the page does not reflow when data lands | No skeleton component exists. Loading uses Bar Loader plus placeholder '—' values in KPI Card; Bar Loader's copy ('Please wait / This might take a few minutes') is not exposed as a property, so it cannot name what is loading. |
| All '/ empty' frames | An empty-state pattern that names what will appear and offers the next action | No empty-state component is published. The DS file has a WIP 'Empty State Banner' page, but it is not in the library. Empty states use Inline Notification (Info / Warning / Success) plus Button. |
| 03 - Document Extraction | An extracted-term reconciliation row: extracted value, source excerpt, editable override, confidence, accept / correct in place | No such control exists. Rendered as a composed row with a Badge for confidence (Success / Warning / Error, each with a text label). Accept / correct / override are not represented. |
| 03 - Document Extraction, 08 - Position Detail | A source-excerpt popover: highlighted citing sentence, document / page / clause reference, deep link, plus 'resolving' and 'could not be located' states | Tooltip carries a single label and Dialog is modal. Rendered as a static 'Source Passage' panel (surface/subtle, label_s caption, body_s quote) without its two failure states. |
| 04 - Borrower Profile | A challenge flag that holds evidence and records an accept / dismiss decision | Inline Notification is informational, with no actions or decision record. Rendered as a Warning Inline Notification; adjudication is not represented. |
| 05 - Corporate Structure | A structure canvas with entity nodes, guarantee overlay and keyboard-navigable tree | No tree or graph component exists. Rendered as the wireframe's indented outline equivalent, with Badge for 'Unrated offshore' (Warning) and 'Unverified' (Error). |
| 07 - Portfolio Watch, 08 - Position Detail | A covenant-headroom meter with a fixed threshold marker, signed distance, breached and 'no current data' states | Meter exposes Label and Data text only. Its fill level is not settable, so every instance shows the component's default fill (including 'No current data'), and there is no threshold marker or unknown state. The text carries the meaning; the bar does not. |
| 06 - Risk Review | A review thread (open / answered / resolved / blocking, with reply) | No thread or accordion component exists. Threads are Inline Notifications (Error = blocking, Info = open), with no reply or resolve affordance. |
| 02 - Precedent Search | A desk-attribution chip with own-desk / other-desk / restricted variants, and the relationship map from the page spec | Badge has only status types; 'Other desk' uses Badge/Warning. The wireframe frame has no relationship map and the DS has no graph component, so the map is not built. |
