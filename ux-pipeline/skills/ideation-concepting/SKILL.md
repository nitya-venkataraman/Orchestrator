# Ideation & Concepting

## Steps
1. Read `problem_statement` and `persona_profile`.
2. Brainstorm feature ideas addressing each HMW statement.
3. Score each feature on an Impact/Effort matrix (High/Med/Low each axis).
4. Propose 2-3 distinct UX concept directions (name, summary, key differentiator).

## Output contract
Return `feature_matrix` (markdown table) and `concept_proposals` (list of concept summaries). Do not select a winner — that is a human decision at the HITL gate.
