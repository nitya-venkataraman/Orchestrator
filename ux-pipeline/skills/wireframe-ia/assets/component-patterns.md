# Superlap Component Patterns (for Wireframe Reference)

## Poster Event Card
- 1px solid black border, 0px radius, single flat category-accent background fill.
- Layout: small category tag (upper-left), optional rounded tracking badge (upper-right, radius-full), large centered headline (lower half).

## Text-as-Button CTA
- No filled button shapes. Bold uppercase black text + directional arrow (e.g. "LET'S RACE →").
- Hover: horizontal translate on arrow/underline, no shadow/color-fade.

## Announcement Ticker Marquee
- Full-bleed horizontal bar, accentPink background.
- Infinite-loop micro text (10px, uppercase, 0.75px tracking), white or black ink.

## Minimal Form Input
- No background box; single 1px black baseline rule.
- Bold uppercase placeholder text (e.g. "EMAIL ADDRESS").

## Grid Collapse Rule
- Desktop: 3-column masonry grid, equal-height hard-bordered blocks.
- Tablet: 2-column. Mobile: 1-column.
